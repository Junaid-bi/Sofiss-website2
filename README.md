## 🚀 1-Click Launch to GitHub (Free Hosting with SSL)

This entire website is packaged into a zero-dependency, self-contained `index.html` file that includes all high-resolution product photography, nutrition cards, interactive cart, checkout UI (Razorpay/PhonePe), and admin management.

### Method A: Upload Directly via GitHub Web UI (Easiest - 1 Minute)
1. Go to [GitHub](https://github.com/) and click **New Repository**.
2. Name the repository `sofiss-website` (or `sofiss`). Set it to **Public**.
3. Click **Upload an existing file**, drag and drop all files from this folder (`index.html`, `README.md`, `.gitignore`), and click **Commit changes**.
4. Go to **Settings** > **Pages** (in the left sidebar).
5. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
6. Your website is instantly live at:
   `https://<your-github-username>.github.io/sofiss-website/`

## 🌐 Connecting Your Custom Domain (`sofiss.in` or `sofiss.com`)
1. In your GitHub repository, navigate to **Settings** > **Pages**.
2. Under **Custom domain**, enter `sofiss.in` (or `www.sofiss.in`) and click **Save**.
3. In your domain registrar DNS settings (GoDaddy / Hostinger):
